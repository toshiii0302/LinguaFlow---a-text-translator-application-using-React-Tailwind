# LinguaFlow Translator

A language translation web application built using React, Tailwind CSS, Axios, and RapidAPI.

## Features

- Translate text into multiple languages
- Responsive UI
- Character counter
- Copy translation feature
- Clear input/output functionality

## Tech Stack

- React
- Tailwind CSS
- Axios
- RapidAPI

## Setup

1. Install dependencies

npm install

2. Create .env file

VITE_RAPID_API_KEY=YOUR_API_KEY
VITE_RAPID_API_HOST=google-translate113.p.rapidapi.com

3. Run project

npm run dev
